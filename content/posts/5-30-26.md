It has been more than two years since I bought a [Pinecil soldering
iron](https://pine64.com/product/pinecil-smart-mini-portable-soldering-iron/)
and wrote about [soldering the breakout
board](https://danielmangum.com/posts/risc-v-bytes-soldering-pinecil-breakout-board/)
and [accessing the
UART](https://danielmangum.com/posts/risc-v-bytes-accessing-pinecil-uart-picoprobe/).
I've been doing more work with the Pinecil as of late following the addition of
[upstream support](https://github.com/zephyrproject-rtos/zephyr/pull/94004) for
the [Bouffalo Lab BL706
MCU](https://en.bouffalolab.com/product/?type=detail&id=8) in
[Zephyr](https://zephyrproject.org/) (big shout out to
[@VynDragon](https://github.com/VynDragon),
[@will-tm](https://github.com/will-tm), [@josuah](https://github.com/josuah),
and everyone else who has been contributing to the upstream Bouffalo Lab
efforts!).

While accessing the UART is helpful for viewing logs, debug access is critical
when chasing down early system initialization and driver issues. While there are
a variety of JTAG probes on the market, I typically reach for my
[JLink](https://www.segger.com/products/debug-probes/j-link/) due to its broad
compatibilty and robust tooling. In order to connect a JLink to the Pinecil, the
[breakout board](https://pine64.com/product/pinecil-break-out-board/) described
in my previous posts is required. It includes a 10-pin header for JTAG breakout
with a 3v3 reference pin, 4 GND pins, and the standard JTAG signals. While there
are [many
adapters](https://www.segger.com/products/debug-probes/j-link/accessories/adapters/overview/)
for attaching various debug pinouts to the JLink 20-pin connector, it is easy
to use female-to-female dupont wires to connect the standard 2.54mm pins on the
Pinecil breakout and the JLink. The diagram at the top of this post illustrates
the pin mapping, and the image below shows the wiring with a ribbon cable
between the wires and the JLink (with female-to-male dupont wires), which can be
useful to avoid having to reconnect the pins each time if needing to use the
JLink for other purposes between Pinecil debugging sessions.

> If using a ribbon cable, it can be easy to get confused about orientation when
> mapping pins. With the notch upwards, the `VTref` pin (pin 1 on JLink, see
> white wire below) is in the top left corner of the ribbon cable pinout as it
> needs to mate with the `VTref` pin in the top right corner of the JLink
> pinout.

{{< center-img src="../../static/jlink_jtag_pinecil_1.jpg" alt="jlink-jtag-pinecil-1" >}}

After connecting, `JLinkExe` can be used to verify that the mapping is correct.
The `VTref` connection to the breakout board's 3v3 pin should allow the JLink to
detect the logic voltage level (~ `3.3V`).

```
JLinkExe
```

To attach a debugger, such as `gdb`, `JLinkGDBServer` can be used to connect to
the JTAG circuitry on the underlying [SiFive E24 core
complex](https://www.sifive.com/cores/essential-e-series) in the BL706 MCU and
start a local `gdb` server on port `2331`.

```
JLinkGDBServer -device E24 -if JTAG
```

The following `gdb` command can be used to connect to the server and load the
firmware symbols.

```
gdb -ex 'target remote :2331' ./path/to/firmware.elf
```


From there you can start stepping through instructions.
